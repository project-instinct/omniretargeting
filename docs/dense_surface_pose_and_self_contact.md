# 全身自接触与稠密表面姿态

`self_contact.enabled` 和 `surface_pose.enabled` 默认开启。真实表面、标定机器人
参考姿态具备时，场景接触、自接触和全身姿态共用一次学习对应；没有场景也能建立
姿态和自接触任务。实现依据 [UMR III-B/III-C](https://arxiv.org/html/2609.02134#S3)：
固定索引表面对应、接触向量，以及相对参考姿态的表面朝向变化。代码独立实现。

## 通用自接触

新路径使用 `barycentric_skin/full_body`，其中 `sample_joint_indices` 和
`joint_parents` 描述源拓扑。逐帧在原始米制皮肤上查找 2 cm 内、法向相向的点对，
排除同一源段、直接相邻源段、同一机器人刚性部件及相邻机器人刚性部件。
还排除参考皮肤上的测地近邻（默认 12 cm，三角网格边路径近似），避免腋下、腹股沟
等连续皮肤在标签边界被误判成新的自接触。两端面内距离也计入路径，查询按样本缓存。
算法没有手、大腿、胸腹等部位名称分支，可以发现双手、手—躯干、前臂—上臂等关系。

每对源段维护一对材料点：只要原配对仍满足接触条件，就不因最近邻名次变化而换点；
释放后终止，新的实际接触建立新事件。默认保留单帧短触碰，不延长或平滑接触区间。
一个源段可同时接触多个非相邻源段；同一源段对当前只选一个接触点对，不能视作完整
接触面或接触力估计。采样密度和对应质量仍会影响召回率。

`sample_effectors` 把源表面样本关联到已有主要末端任务。任一侧正在接触场景或物体时，
相应主要末端不再被自接触吸附。其他适配器应提供自己的标签，不由通用模块猜名称。

接触向量以接收方机器人 geom 的局部坐标表示。目标通过源接收面的相对旋转运输，
保持原来的米制向量；法向同样运输机器人参考法向。两侧平移与旋转均进入 Jacobian，
共同根部运动不产生自接触误差。已有独立几何自碰撞约束继续工作，不豁免接触对。

旧的 `parts` 输入继续走区域投影路径，保持原有三帧短段过滤兼容性。有 `full_body`
但缺少可靠拓扑时明确报告 `missing_source_topology`，不会宣称已运行通用自接触。

## 非接触表面也驱动姿态

`SurfacePoseTasks` 对全部有效学习对应建立位置与法向目标，包括从未接触过环境的点。
不再要求一个点先进入场景接触，才能为姿态提供信息。默认每部位总权重 0.2，位置尺度
0.05 m，法向尺度 0.35；固定的部位归一避免活动点数变化引起权重跳变。

自由位置目标为机器人当前根部加上源根部相对位移、参考形态比例，以及随源面旋转的
参考表面偏移。默认形态比例由有效参考点云跨度估计，末端使用既有
`swing_morphology_scale`。这是目标构造，源数组、人体轨迹、场景和机器人尺度不变。
目标对机器人根部的导数与 FK 一起计算，避免错误地把根部平移算成自由手姿态误差。
配置为 `preserve_world_target`，或由适配器通过 `sample_world_tracking` 标记的脚部
表面，直接保持原始世界表面位置，不叠加形态比例或参考偏移。这样没有末端 profile
的源也不会把脚部默认为根部相对目标。

主要末端正在接触时，其刚性部件上的自由位置项关闭；已有场景接触点和自接触点也不
再叠加自由位置目标。场景接触继续使用同一世界环境点与接触向量。场景接触点的参考
法向已进入主求解，姿态任务跳过同一点的重复法向项。其他点的法向独立于接触状态。
单个法向不约束绕该法向的转角，多点表面位置/法向共同提供姿态信息。

## 求解、保护与诊断

后续增加了[接触角色](contact_phase_priority.md)：静态场景上不滑动的接触为支撑，其他接触
为跟随，确认离开表面的末端为自由，求解按支撑 > 跟随 > 自由 > 姿态排序。自由的世界末端
不再被下述基准保护钉住；其余仍使用下述默认保护。角色不代表承重能力已经验证。

- 逐帧 SQP：稠密位置、法向和自接触进入身体目标，新增项应用前计算同状态的末端
  基准，并加逐末端误差上界。原手脚优先级保留。此保护在当前线性化步内成立，
  完整非线性轨迹仍由最终几何和接触验收检查。
- 整段求解：通过通用 `extra_tasks` 接口传递同一任务。启用这些新任务时，使用稀疏
  Clarabel 子问题和非线性回溯，保护输入轨迹的主要接触、世界脚部，以及已建立的
  自接触/场景表面预算。预算固定，不逐次累计。保护已有误差不等于已达到零误差。
- 轨迹细化、自碰撞投影、局部修复、全身修正：显式传入同一姿态任务，保持原时间
  索引。自接触仍复用原有逐点接触保护。固定根部的修正阶段不会为改善表面目标移动根。
- 历史脚部基准/手部叠加模式继续延后场景表面接触构建，避免改变原来的阶段约定。

诊断分别记录 `self_contact`、`surface_contact`、`surface_pose`；姿态误差分为米制
位置误差与弧度法向误差。NPZ 导出源 face/barycentric 身份、机器人绑定、位置目标的
根部相对标记、有效掩码和法向目标。缺数据、缺参考或显式关闭都有具体原因。

```json
{
  "retargeting": {
    "self_contact": {"enabled": true, "min_contact_frames": 1},
    "surface_pose": {"enabled": true, "weight": 0.2}
  }
}
```

核心为 `surface_motion.py`、`full_body_self_contact.py`、`surface_pose.py`；SMPL-X
适配器只增加源拓扑、主要末端/世界目标标签和 shaped-rest 参考关节位置；根据实际
选择的根关节取参考位置，不把 torso 根误配到 pelvis，不把源专属解析塞进求解器。
对应仍使用现有关节链约束；本改动不声称实现完全免人工骨架映射的 UMR 全流程。

回归覆盖通用部位配对、相邻排除、两侧场景接触优先、短触碰/释放、双端 Jacobian、
根部平移不变性、世界脚部语义、无场景姿态任务、逐帧/整段求解和后处理接线。
实际录制片段的运行范围和分项指标见本地
[验证记录](../out/umr_surface_extension_20260922/RESULTS.md)。该记录只覆盖 12 帧有界
修正检查；接触仍有残差，场景查询仍有未知区域，不代表整段录制已经验收。
