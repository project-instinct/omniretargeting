# 全身表面场景接触映射

新增通用全身自接触、非接触表面位置/法向主求解和共享对应准备，见
[全身自接触与稠密表面姿态](dense_surface_pose_and_self_contact.md)。本文的历史 A/B
结果不包含这次扩展。

`retargeting.surface_contact.enabled` 默认开启。有真实全身表面数据、已标定的
机器人参考姿态和场景网格时，自动建立人体—机器人表面对应，并把源动作中的
全身场景接触映射到机器人。前臂、上臂、躯干、骨盆/臀部、大腿、小腿、头和
手脚使用同一条路径，不需要为每种接触再配置一个机器人末端。

算法依据 [UMR 论文 III-B/III-C](https://arxiv.org/html/2609.02134#S3)，并核对官方
[`d6bb7612` 对应学习实现](https://github.com/hanyang9/UMR/blob/d6bb76123d19afb7c2c1c84162d1af1f142a61ed/scripts/train_correspondence_template_residual_ae.py)。
代码为独立实现，不导入官方代码、权重或机器人资产。

基于 UMR `e24fc070` 重新核对的受约束全身求解、运动物体避碰与验收计划见
[方法对照计划](umr_constrained_whole_body_plan.md)。其中明确区分官方机制、
本项目已有实现及尚待实现的扩展。

## 固定表面对应

SMPL-X 适配器在真实 shaped-rest 网格全身按面积采样 2048 个点，保存三角形
编号和重心坐标。运动中只更新这些三角形，重采样不更换点的身份。适配器提供
的皮肤部位标签用于分组诊断和权重归一。皮肤主导关节及父子关系与既有
`joint_mapping` 一起限定对应所属的机器人关节链，避免几何相似的左右肢体、
上臂和前臂互相替代；通用学习模块不包含 SMPL-X 专属名称。
既有 `parts` 数据仍供手—大腿自接触使用；新的 `full_body` 数据供全身场景接触使用。

`surface_learning.py` 从已标定的机器人参考姿态采样实际碰撞壳。PointNet 式
编码器对机器人点云取全局特征，MLP 按人体点的固定索引预测形变向量。训练包含：

- 双向 Chamfer 覆盖项；
- 近邻点排斥项，减少对应塌缩；
- 沿人体参考网格测地邻接的形变平滑项，避免隔着空气连接相邻肢体。

测地距离采用三角网格边图近似，样本锚定到所在三角形的一个顶点。网络在每个
源体型/机器人参考姿态组合上训练，采用较小的网络和 CPU 求解；它不是官方
预训练模型，也不声称与官方输出逐点相同。学习和投影都限制在对应的关节链表面内。
未映射的源关节继承已映射的最近祖先，继承关系和没有碰撞表面的区域逐项报告。
没有关节映射信息时，诊断明确标记几何对应的回退。学习后的点投影到实际碰撞壳，
保存 geom 与局部坐标；投影太远、参考法向不一致或跨身体中线的点被禁用并报告。
中线检查使用已对齐参考坐标系中的几何位置，不依赖机器人左右肢体的名称。
默认横向轴为参考世界的 Y 轴；其他参考坐标约定可配置 `correspondence.lateral_axis`。

参考点云的平移与统一尺度归一只存在于对应学习内部。机器人 FK、源运动、场景、
接触目标始终保持原来的米制坐标。缓存由源网格、采样身份、机器人参考几何、
参考 qpos 和训练参数共同决定，默认位于
`~/.cache/omniretargeting/surface_correspondence/`，使用不需要 pickle 的 NPZ。

## 接触向量与优先级

对每帧人体表面点 `h_i(t)`，查询场景或原始运动物体的最近点 `y_i(t)`。
近接触同时检查距离（默认 3 cm）、人体/环境法向相对朝向，以及在物体材料坐标
中计算的相对法向速度。8 mm 内的短暂触碰可保留；高速擦过较远表面的样本会被
拒绝。按相对切向速度区分 sticking、sliding 和 touch，这些是几何运动分类，
不代表接触力或支撑已经成立。保存 `c_h = h_i - y_i`，并向机器人分配同一环境点：

```text
c_r(q) = robot_surface_i(q) - y_i
residual = c_r(q) - c_h
```

环境点及源向量在优化前固定。机器人不能通过重新找一个较近的场景点来降低
残差。滑动时目标跟随源侧的场景点分配与接触向量；离开接触阈值后没有吸附项。
默认不删除单帧接触，不延长接触时段，不强制把接触变为静止锚点。没有接触的
表面点不产生人体世界位置跟踪目标。

逐帧保留已有手脚接触的最高优先级。学习得到的全身表面接触向量按 UMR 的
加权方式与姿态共同优化，默认 `weight=5`、`sigma=0.015 m`。每个源部位的
任务总权重使用整段固定的部位归一系数，并乘以每点距离/朝向置信度。一个点
释放不会突然放大同部位其他点的权重；源位置和接触时段不经过低通滤波。
参考对应是近似值；把每个近表面样本都设为独占优先级可能放大局部对应误差，
破坏脚部运动和时间连续性，因此默认使用 `priority="balanced"`。
显式选择 `priority="after_end_effectors"` 可以启用手脚之后的单独表面接触层，
只适用于对应与动作已验证的实验。

新增表面目标求解前，从同一 SQP 状态先计算没有该目标时的端点解，再逐端点
加入误差上界（默认余量 `endpoint_regression=0.001 m`）。这样额外表面项不能
在该线性化步骤中任意购买脚部误差；不可达端点保留可达的基准误差。该约束不是
整段非线性轨迹相对关闭组的误差证明，仍须用完整动作对照验收。

同一个 `SurfaceContactTasks` 对象传入轨迹细化、自碰撞投影、局部避碰和候选
验收。后处理的逐点向量误差上限为 `max(基准误差, tolerance) + regression`，
默认分别为 1 cm 和 2 mm。窗口沿用原时间索引；浮动基座沿用既有固定策略。
这限制后处理新增的退化，不代表初始解已经达到 1 cm。

## 配置、输出与边界

```json
{
  "retargeting": {
    "surface_contact": {
      "enabled": true,
      "distance": 0.03,
      "min_contact_frames": 1,
      "sigma": 0.015,
      "weight": 5.0,
      "priority": "balanced",
      "tolerance": 0.01,
      "regression": 0.002,
      "correspondence": {
        "iterations": 300,
        "cache_dir": "~/.cache/omniretargeting/surface_correspondence"
      }
    }
  }
}
```

没有真实全身皮肤数据、标定参考或场景时，运行诊断报告明确的 disabled 原因。
直接传入关节数组不会被伪装成全身表面。新增的通用求解接口不依赖 SMPL-X
关节名；其他适配器可以提供相同的 `barycentric_skin/full_body` 数据契约。

保存的动作 NPZ 新增 `surface_contact_*` 字段，包括接触 mask、世界目标、
场景点、源接触向量、源 face/barycentric 身份及机器人 geom/local point。
诊断 JSON 的 `surface_contact` 独立报告逐帧初解和最终接触向量误差、各部位
误差及最差帧，不能用几何避碰结果代替接触保持指标。

OMOMO 入口复用真实 SMPL-X 表面和标定元数据；`trans` 直接传入模型，避免重复
添加 `trans2joint`。原始 `obj_scale/obj_rot/obj_trans` 一起确定实际物体几何，
数据自身的网格标定尺度不等于对场景或机器人额外缩放。

运动物体同时接入全身表面观测和主要手脚接触推断。`object_contact.py` 在物体
坐标中判断相对速度，世界目标随原物体位姿更新；抓住移动物体的手不再因世界
速度高而被当成自由手。`contact_environment_ids` 区分静态场景（0）和物体
（1..N），运动物体锚点不会被用作静态场景的内外侧证据。
主要末端的 `anchor_contacts` 同样适用于运动物体：每段 sticking 固定进入接触
时的物体材料点及法向，再由原始物体变换送回世界坐标。最近人体样本交换排名
不会让抓握目标在物体表面跳动。滑动、释放和切换物体会结束该锚点；显式关闭
`anchor_contacts` 时保留逐帧投影。全身表面向量仍逐点保留源侧映射与运动。
脚部基准轨迹/手部接触叠加流程使用合并后的接触计划决定是否启用。即使手只接触
运动物体，也会先生成完整脚部轨迹，再在该轨迹上做局部手臂修正；不会因静态
地面查询没有手部接触而把腿和基座冻结在初始姿态。
叠加首帧沿用基准轨迹的根位置、方向和初始标定偏移，避免在局部手臂求解前
重新写入人体根姿态，破坏已经求好的脚部位置。
全身表面项不参与仅有脚部任务的基准阶段，避免提前改变身体姿态后，让局部
手臂求解面对不可达的抓握目标。表面项进入后续接触叠加或非分阶段的全身求解。
手部释放后，若其他表面仍有接触，该帧继续求解对应碰撞体的关节祖先链，固定
浮动基座和不相关关节；不会因主要手部接触结束而跳过其他身体部位的接触。
`local_contact_chain_only` 配置仍限制手部叠加的可动关节；在这一配置下，不能
把这一阶段的骨盆/躯干表面残差解释为已解决。后续默认开启的
`whole_body_correction` 以有效机器人轨迹为固定基准，开放活动表面祖先和手脚
补偿链，联合改善接触、参考姿态法向与碰撞。手部接触不再冻结这一新阶段的腰腿。
默认抓握误差最多增加 1 mm、脚部位置最多偏移 2 mm；根保持固定。

新增运动物体查询同时进入全身修正的目标和非线性验收；帧间检查包含物体运动。
闭合组件与开放表面的反向交叉证据分开处理，未知组件仍然未知，不能声称无碰撞。
具体实现和不可动根体等限制见 [受约束全身修正](constrained_whole_body_correction.md)。
开放场景的折边采用相邻面共同检验，不能可靠定侧时保留不确定。局部修复和后处理
逐组件复查固定机器人表面点，保护已知样本，不允许把已知穿透移进不确定区域
来消除报告。未知区域不会阻止其他可靠穿透的有界修复，但最终仍报告 unresolved。

本文最初的场景接触改动没有扩展自接触；后续已增加共享学习对应的通用全身自接触，
旧的手—大腿路径为 `parts` 输入保留。几何近接触
不等同于接触标注或力学支撑；本实现不估计接触力，也不能保证碰撞为零。
碰撞体的曲面离散近似和参考对应仍可能留下误差，应结合实际动作检查。
