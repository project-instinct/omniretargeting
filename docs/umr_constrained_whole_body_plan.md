## 必须明确的差异

1. UMR 的统一表面加权目标不等同于本项目的手脚保护约定。我们把已有抓握、脚部世界位置和动作偏差作为固定基准约束，在这些约束内改善其他表面接触和碰撞。
2. 同环境点接触残差 `(x_robot-y)-(x_human-y)` 等于 `x_robot-x_human`。它保留分配和加权关系，但不约束身体其余位置，因此必须有独立几何避碰。
3. 官方代码包含按身高缩放人体与物体轨迹的路径。我们保持人体、机器人、场景和物体运动的原始尺度；自由姿态目标通过参考姿态校准和身体相对表达适配形态，接触目标保持世界坐标。
4. 官方这一版本的 HSI/HOI standard defaults 中，`object_contact_map_cost=0`、`robot_object_hard_constraint=true`、碰撞 slack 开启；实际生效还依赖数据和调用路径。不能照抄默认文件后就声称接触项已运行。我们记录实际活动的目标、碰撞行和松弛。
5. 官方表面法向采用参考姿态变化运输；我们采用这个思想，避免直接要求人体皮肤法向与不同形态的机器人表面法向相同。具体部位权重需实测，不将官方零权重区域全部强行开启。
6. 官方的全自由度求解和后滤波不是本项目固定根路径与接触保持的保证。我们默认固定浮动基座，正则化新增修正，并在非线性 FK、几何和帧间检查后接受候选。

## 实施顺序

### 1. 固定数据、对应和当前有效机器人基准

- 以 `out/whole_body_fixes_20260914/omomo_ab/contact_plan_fixed/on_retargeted.npz` 为本轮修正基准；复用原始 115 帧、30 Hz、源标记、物体变换和固定表面图。
- 将末端接触材料点选择也固定到基准，求解和验收沿用同一身份；不能靠换一个掌面点降低误差。
- 先核对骨盆/前臂活动点及其运动链、可动 Jacobian、目标冲突，区分错误对应、被冻结和暂时不可达。

### 2. 统一全身关节修正

- 从活动表面与碰撞体的祖先关节确定可动集合，并加入受影响手脚的补偿关节链；其他关节固定。主要手接触存在时不能再次被 arm-only 分支覆盖。
- 默认固定浮动基座。使用固定基准的总关节改变量、速度和加速度预算，防止每次小步重置基准而累积漂移。
- 联合表面向量、参考姿态校准后的表面朝向、现有身体姿态与时间一致性目标。自由手保持身体相对姿态，脚始终保持世界位置目标。
- 末端验收预算为抓握逐帧新增误差 1 mm、脚部相对基准移动 2 mm；它们是本项目的保护预算，不是 UMR 默认值。完整对照已通过这些预算，实际残差见报告。
- 对 sliding 同时约束法向接触退化和切向跟随退化，避免只贴住表面却沿表面偏移。

### 3. 运动物体几何和约束

- 固定物体局部几何及其内容摘要，逐帧仅更新原始平移、旋转和尺度；缓存物体局部加速结构。
- 当前使用原始网格的可靠闭合组件，不引入凸分解代理。若后续增加代理，需要另行验证其与原始网格的一致性，不能把开放扫描的含糊内外关系改成确定事实。
- 接触与穿透分开处理：接触允许贴面，其他可靠交叉由 signed clearance、完整方向及机器人 Jacobian 修正。
- 对开放碎片补充物体表面进入机器人碰撞体的反向检测；固定物体材料样本身份，保留采样范围和未覆盖区域。
- 不可兼容时保留并报告碰撞松弛；不能牺牲手脚、移动源数据或忽略查询失败来使报告变好。

### 4. 轨迹耦合、实际几何与接受/回退

- 新阶段复用 `TrajectoryValidator` 和后处理保护，在同一个轨迹子问题中联合求解所有帧。新增修正的时间差分受约束，不需要拼接独立帧的修正。当前回溯步长作用于整条输入轨迹，局部困难帧可能限制整段更新；尚未实现重叠窗口调度。
- 帧间使用相同时间插值更新机器人与物体，细分依据包含物体平移、旋转和尺度变化。静止机器人也必须检查快速移动物体。
- 对候选重做真实 FK、原始几何、固定接触身份和帧间检查。已知样本变为未知不能作为碰撞消失的证据。
- 当前最深椅子交叉位于 `torso_link` 浮动根体。固定基座时，腰腿和手臂不能移动该体；仅在符合项目规则的共同向上退出、小幅机器人根高度调整条件下考虑根修正。其他不可修复交叉明确保留。

### 5. Luna 验证与交付

- 主 agent 负责实现、方法对照与审查；Luna 负责测试、几何探针、性能测量和真实数据对照。
- 先验证：主要手接触与骨盆同时活动的关节选择、参考法向运输、移动物体距离方向/Jacobian 的有限差分、机器人静止但物体跨越的帧间交叉、凹椅空隙、固定接触身份和不可动碰撞。
- 再跑骨盆最差帧 37、椅子交叉帧 0、滑动帧 113–114 的有限窗口。通过后跑完整 115 帧，复用已核实基准，不重复生成无变化的脚部基准。
- 对照当前基准、受约束全身修正、全身修正加运动物体避碰三组。分别报告末端世界误差、各部位表面误差、修正幅度、jerk RMS/P95/峰值、可靠穿透/反向交叉/未知，以及求解失败和回退原因。
- 给出原始尺度、同视角动画和最差帧图。接触或穿透需有实际改善，且守住固定手脚与动作预算；零可行更新必须如实报告。
