# 原始网格穿模修复提速（2026-09-27）

对象：fast 后端的 `_fast/mesh_repair.py`（接触获取之后，用原始三角网格检查并修正穿模）。
结果与改动前逐位一致；只改变计算方式。

## 瓶颈证据

omomo_78 G1，接触获取后的同一输入（`omomo_78_g1_relation_envelope`）：

| 路径 | 修复前占比 |
| --- | ---: |
| 原始网格测量 `OriginalGeometry.measure` | 76% |
| 其中运动物体（箱子）查询 | 45% |
| 其中静态场景（地面） | 约 19% |
| 其中自碰撞 | 10% |
| 可行性恢复 `restore_repair` | 11% |
| 修复 QP | 5% |

前 7 个修复步做了 32 次整段测量、约 4 亿个静态点查询（地面只有 12 个三角形，绝大多数采样点
离地面很远）和 8800 万个箱子开放面采样查询，且全部在单核上执行。

## 改动

1. `_fast/parallel_geometry.py`：修复开始时 fork 常驻子进程，每个进程固定负责一组交错帧，
   自己的精确缓存始终有效；父进程按帧顺序合并。完整测量与串行逐位一致（被拒候选见下文第二轮）。
   每个子进程绑定到自己的 CPU 核，避免 libigl 在每个进程里按全机核数开线程造成过载。
2. 静态场景：所有部件都是用绕数判符号的闭合网格时，有符号距离是 1-Lipschitz 且远离表面时
   可靠。若某部位上次的精确最小间隙减去其采样点最大刚体位移仍不小于 8 mm 见证带，则直接复用
   上次结果（无见证行、已知），缓存保留的是精确查询时的位姿。开放或依赖证据的部件始终重查。
3. 运动物体开放面：先用证据点距离筛出范围内的采样点，再只对这些点求最近三角形；最近三角形
   按点独立计算，范围外的点原本就不使用它。

## 实测

同一输入、同一机器，最终动作、77 步修复历史、修复前后穿模报告逐位一致：

| | 串行 | 并行 + 去重 |
| --- | ---: | ---: |
| 原始网格修复 | 4537 s | 1244 s（3.65 倍） |
| 每步 | 59 s | 16 s |

改动后父进程中测量只占约 1.4%；`restore_repair` 的锥规划求解约占 66%，修复 QP 约占 31%。
这两部分是算法本身按顺序依赖的求解，进一步提速需要改变求解规模或步骤，会改变结果。

## 测试

`tests/test_original_geometry_batches.py`：并行与串行（完整接受和在其他进程负责的帧上截断）
逐位一致；闭合地面上远处部位复用且与逐帧重查一致，贴近地面时重新查询；开放场景不复用。

## 接触获取提速

接触获取每轮先算普通 LM 步；目标函数里没有接触保护，普通步常把站立脚抬高而被拒，只能改算
带约束的锥规划备用步（约 6.3 万变量、16.5 万约束，每次约 25 s，每轮含恢复多次）。现在把
接触获取保护（`AcquisitionNormalGuard`）同时作为刚性单侧铰链项加入目标函数，
普通步即满足其一阶约束；验收仍逐一检查原保护。

| omomo_78 G1 | 接触获取 | 全流程 | 左手 / 右手接触误差（均值） |
| --- | ---: | ---: | --- |
| 改前 | 1541 s（10 轮） | 2095 s | 5.5 / 5.2 cm |
| 改后 | 577 s（6 轮） | 1320 s | 5.5 / 5.6 cm |

锥规划中还会略去步长盒内不可能触及的姿态约束（最优解不变，已测试）；界较保守，只省约 15%。
目前剩余最大耗时为原始网格修复中的可行性恢复锥规划。

## 第二轮：修复本身（692 s → 205 s）

输入：`omomo_78_g1_general_posture6` 的接触获取结果（回放，只重算修复）。修复历史中大部分
候选被拒：手部各组因 `lost original source-side observation`（箱子开放面上原本穿模的采样点移出
证据范围后变为未知，按规则不能当作无碰撞），线搜索每个步长都要整段测量；完整步长又常因
0.1 µm 级的超限触发 2–4 次恢复锥规划。

改动（接受/拒绝判定和验收阈值都不变）：

1. 被拒候选提前终止：任一子进程发现拒绝帧，所有子进程停止；候选先查最近被拒过的帧，再按
   相对上次完整测量的改动量从大到小。完整测量仍逐位等于串行；被拒候选的行、报告帧和查询计数
   只是部分诊断。
2. 箱子开放面查询：只遍历有采样点的部件（顺序不变）；`OpenSurfaceFeatures` 用普通数组和向量化
   分组代替逐行 Python 循环和 trimesh 属性访问；三处证据点近邻查询加上略大于证据半径的搜索
   上界（只剪枝，超出者本就不合格；随机开放网格上与原查询逐位一致）。
3. 自碰撞：`SelfCollisionQuery.query(reuse=...)` 按两个几何体的精确位姿复用上一次该帧的
   逐对结果（`tests/test_self_collision_reuse.py`）。
4. 修复 QP/恢复：`LinearBounds` 精确略去关节盒内不可能违反的行与锥（盒本身保留），并把系数
   完全相同的行（多个守卫重复的时间差分）合并为区间交集，可行集不变
   （`tests/test_repair_bounds_pruning.py`）。
5. `LinearBounds.norm` 与接触获取守卫一致：线性子问题只用验收 1e-7 容差的一半，另一半留给
   曲率和舍入；已用完容差的已接受位姿仍可行。此前完整步长常以 1.0–1.5e-7 m 超出
   `free endpoint fidelity`，每次都要恢复锥规划。恢复次数 32 → 14。

| omomo_78 G1 修复回放 | 改前 | 改后 |
| --- | ---: | ---: |
| 原始网格修复 | 692 s | 205 s |
| 几何测量 | ≈280 s | 88 s（86 次） |
| 恢复锥规划 | ≈215 s | 55 s（14 次） |
| 修复 QP | ≈99 s | 47 s（29 次） |
| 修复前 → 后最大穿模（地面 / 箱子 / 自碰撞） | 2.60→2.41 / 5.12→5.12 / 0.73→0.72 cm | 相同 |

计时在同一台机器上、有其他负载时测得，有约 10% 波动。第 5 项会改变 QP 提出的步长（约 1e-8 量级），
所以修复路径与改前不逐位相同，最终穿模指标相同。直接用 CLARABEL 求恢复问题（绕过 cvxpy）
经配对测试没有稳定收益，未采用。

仍未解决：箱子穿模（手腕约 5.1 cm）不是速度问题。手部候选全部因证据范围外的采样点变为未知而被拒，
需要单独处理这一判定。

## 第三轮（2026-09-28）：接触获取锥规划的精确去重、箱子几何判定

与 Codex（gpt-6-astra）评审（`out/codex_20260928/review.md`、`residuals.md`）合作完成。

**接触获取锥规划去重（可行集不变）**

- 两个姿态包络（种子 `stage_0` 与冻结参考 `fixed`，二者只在 11 帧四元数上差 ≤1.1e-16）
  的成对范数锥中，系数和偏移逐位相同的只保留一个辅助变量，两边的全身/部位求和约束都引用它
  （`pose_relations.cone_constraints`；求和权重非负，故投影可行集相同）。相同的布局行取最紧下界。
  锥规划变量 63000 → 34226。
- 两个连续性守卫（`SequenceContinuityGuard`、`CorrectionContinuity`）重复的标量关节时间行
  合并为区间交集（`shape_step._guard_constraints`，`rows._merge_identical`）。
- 旧几何语义下对照（同一输入）：接触获取主阶段 574 s → 376 s，各轮代价与改前一致到 1e-5 相对量级
  （同一最优解的数值路径差异）。测试：`tests/test_pose_relations.py`、`tests/test_fast_shape_step.py`。

**修复：** 运动物体查询一旦拒绝该帧，不再做该帧的自碰撞/静态查询（判定不变）。

**箱子几何（质量）：** OMOMO largebox 主部件只有 13 条细小裂缝（补洞面积上界为表面积的 0.08%），
却因 12 条非流形边被当作开放网格、只能靠证据判内外；深入 2.7 cm 的采样点移动 0.01 mm 就会从
“可靠穿模”变成“未知”，使手部修复候选全部因 `lost original source-side observation` 被拒。
现对“近似封闭”部件（补洞面积 ≤ 1% 表面积），在证据判不了的点上用补全后实体的绕数判内外
（环的包围球外、绕数离 0/1 在 0.01 内才判定；零体积面片、碎片和真正的开放薄片不变），
第二轮只采纳“在其内部”的结论（`scene_geometry._decisive_winding`、`winding_side`，
`tests/test_decisive_winding.py`）。

**残余穿模的约束定位（Codex 用 QP 对偶证书）：**
- 手腕 5.12 cm（第 99 帧）：被碰撞“不许加深”行本身锁死——腕 roll/yaw 与橡胶手多个见证点
  （正向与反向表示法向相反）的正乘子组合与退出方向相抵（误差 4e-15），1 mm 接触预算是松的。
  需要有限、协调的整体退出候选，而不是逐见证点线性化。
- 脚踝 2.41 cm（第 83 帧）：follow 接触点的“目标误差 + 1 mm”预算、参考上已用满的髋/膝加速度和
  急动度预算、ContactGuard 切向误差共同约束；修复阶段的 1 mm 目标预算与“非穿模优先于接触”
  矛盾（获取阶段已允许按本体穿模深度让步）。

**修复阶段的接触让步（Codex 补丁，审核后合入）：** `RepairLimits` 的纠正组目标预算和其他组的
1 mm 锚点球，都加上该接触所在焊接体在修复入口处原始网格测得的最大静态/运动穿模深度（逐帧；
自碰撞不给让步；干净物体不变），检查与线性化锥共用 `contact_budgets`。ContactGuard 的切向锥
不变，接触点在表面上的横向滑动仍限 1 mm，让步只体现为退出。测试：
`tests/test_repair_penetration_yield.py`。

**姿态关系预算的惰性分离（Codex A2 可行性研究后集成）：** 接触获取的锥规划（方向步与形状恢复）
先不实例化两个包络的全身/部位关系预算及其成对范数，只保留盒、根节点球、布局、全部接触与时间
约束；每次求解后在步长处精确计算所有被省略的预算（范数取实际值），把超出 1e-8 的整族加入重解，
超过 `MAX_SEPARATION_ROUNDS` 轮则加入全部剩余族。无违反时即为完整问题的最优解
（`pose_relations.LazyRelationFamilies`，`tests/test_pose_relations.py`）。离线研究中 8 个真实
问题均一轮通过、关系预算全部不活跃（最小松弛 0.042），锥规划时间 71.9 s → 22.7 s。
- 全流程对照（omomo_78 G1，`general_posture9` → `general_posture10`，只差惰性分离）：总计
  812 s → 633 s，接触获取 474 s → 331 s，修复 240 s → 211 s。前 6 轮代价一致，之后有限精度路径
  分叉，最终代价差 0.1%。箱子 3.80 → 3.79 cm、自碰撞 0.21 → 0.16 cm、手表面接触误差略好；地面
  2.49 → 2.83 cm、左手末端世界误差 7.91 → 8.19 cm 略差。关节预算违例与抖动帧均为 0。这些差异来自
  路径分叉而非问题改变，单次对照不能区分系统性影响。

**地面残余的几何核查（Codex，`out/codex_20260928/floor_residual.md`）：** “G1 脚网格比鞋底接触点低
约 2 cm”的说法不成立——端点只比网格底面高 0.41 mm，第 83 帧活跃的密集采样点离原始三角面
< 0.001 mm。实际原因是蹬离阶段（第 80–87 帧）刚性长脚掌倾斜 15°–57°，脚尖插入地面：源姿态
拟合的种子在第 83 帧已穿入 32.7 mm，接触获取降到 26.4 mm，修复到 24.9 mm；该帧一个脚尖接触点
本身就在地面下 24 mm。不应加脚底偏移、抬高源动作或移动世界目标；需要继续追查的是约束
（逐帧逐关节的时间预算已在参考上用满，以及最后一次修复被 AcquisitionNormalGuard 拒绝）。

## 第四轮（2026-09-28 晚）：非穿模优先 + 窗口时间预算

盘点（posture10）：箱子残余全部是手腕（2–4 cm，约 60–100 帧），地面是右脚蹬离（2.8 cm）。
来源：源形状种子本身手腕插入箱体 12–14 cm；接触获取里每个几何体每帧只有一个最深采样行，
却要对抗每只手几十个接触采样行，结果停在“穿 3 cm、接触差 5 cm”的折中；修复阶段是局部微调，
被逐帧用满的时间预算和见证点冲突卡住（211 s 几乎无改善）。

改动：
1. 接触获取中穿模/自碰撞 sigma 为接触 sigma 的 1/4（`ACQUISITION_CLEARANCE_SCALE`）。1/10 使自碰撞和
   手的误差变差。
2. 时间预算改为窗口定义（`motion_budgets.windowed_budget`：7 个模板内参考导数的最大值 + 该关节 RMS 的
   10%，逐关节逐模板），两个连续性守卫和修复阶段统一使用；验收状态按它判定，逐模板严格比较只作报告。

## 第五轮：接触获取的一致性修正（Codex 诊断 `out/codex_20260928/wrist_acquisition.md`）

1. **根节点旋转上限的一致性。** `FastObjective.project` 把根节点相对参考的旋转裁到 0.2 rad，锥规划与
   形状恢复却不含这一上限，恢复出的状态有 64 帧超过 0.2 rad；下一步即使步长为零，投影也会移动根节点、
   使保护接触越界，接触获取因此提前停止。现把同一上限作为线性化锥加入方向步与恢复
   （`shape_step._root_rotation_cones`，局部坐标右雅可比逆），恢复结果再经投影后检查守卫。
   直接去掉该裁剪的尝试（根朝向只由关系包络约束）结果明显变差（箱子 3.95 cm、手 11 cm），未采用。
2. **穿模残差的雅可比。** 网格的 `gradient` 是插值后归一化的退出方向，与三线性插值的标量残差
   相差 16°–76°。接触获取的穿模行改用同一标量场的精确导数（`GridSDF.value_gradient`），
   LM 的线性模型与实际代价一致，接触获取能持续推进。
