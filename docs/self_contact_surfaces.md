# 身体表面自接触

全身人体—场景接触现在使用独立的学习对应路径，见
[全身表面场景接触映射](whole_body_surface_contact.md)。下文描述的手—大腿
自接触仍采用原有区域投影，两个模块的对应方式和诊断分开记录。

`self_contact` 保留手搭在大腿上的关系；`self_collision` 检查机器人碰撞体
有没有穿进彼此。两个模块同时工作，接触目标不会关闭或豁免碰撞对。

算法参考 [UMR 方法 III-C](https://arxiv.org/html/2609.02134#S3.SS3)
的表面接触向量，以及[官方实现](https://github.com/hanyang9/UMR/blob/main/scripts/smpl_surface_retarget_common.py)
的碰撞距离和双侧 Jacobian 思路。本实现复用已有 MuJoCo 几何避碰，新增
表面接触任务；不移植 UMR 的神经网络，也不声称复现其学习对应关系。

## 数据和对应关系

- SMPL-X 适配器从实际 skinning 权重识别左右掌/腕和大腿区域。每区用
  trimesh 按面积采样 256 点，固定三角形编号和重心坐标。运动与重采样
  只更新这些三角形的位置，采样点身份不变，不保存整段完整人体网格。
- 在源与机器人已标定的参考姿态中，使用区域内相对坐标提出对应位置，
  再用 libigl 投影到机器人实际碰撞表面。法向不一致或投影过远的对应
  会被禁用。曲面碰撞体的绑定使用离散表面近似，最终避碰仍查询原生
  MuJoCo 几何。这个对应方法是工程近似，尚未等同于经过学习的全身表面对应。
- 机器人区域由 profile 的关节映射和运动树确定。腕部包含远端子树，
  因此映射到 wrist roll 的 profile 也能找到 wrist yaw 下的手部碰撞体。
  大腿只取髋到膝之间的链，不把小腿、躯干或另一条腿混进去。
- 坐标归一化只用于选择对应点。源轨迹、机器人尺寸、场景均保持原始
  米制；开启源/场景缩放时拒绝使用这份表面数据。

## 接触任务

目前自动检测双手对双大腿的关系。源侧表面距离不超过 2 cm、法向相对、
至少持续 3 帧才形成候选；已有手部场景接触的帧不会同时吸附到大腿。
这些是从几何推断的近接触候选，不是人工标注的接触真值。

每只手每段接触固定一对表面点，跟踪它们的相对向量和相对法向。
目标表达在接收部位的坐标系中，两侧运动均进入 Jacobian，因此大腿
运动会带动接触位置，机器人根部整体运动不会制造额外残差。源动作
中的切向变化仍保留，释放后没有吸附项。每只手不会因采样加密而获得
更大的任务总权重；接触边界只渐变任务强度，不增加源接触帧。

逐帧求解保留原有场景接触与脚部优先级。自接触作为身体姿态目标的一项
共同优化，接触置信度渐变直接控制它的影响；不把近似表面对应强制变成
一个独占优先级。轨迹细化、局部避碰和候选验收共享同一份固定表面任务。
后处理限制接触向量误差相对基准退化，避免避碰把已经贴合的手拉开。
无法同时满足的接触会保留残差，几何避碰仍按已有容差独立验收。

## 使用与诊断

使用带 SMPL-X 模型的 `--source-config` 路径会自动提供表面样本。
`retargeting.self_contact.enabled` 默认开启；没有真实皮肤数据或机器人
参考姿态时明确报告 disabled。直接调用 `retarget_motion` 的适配器可以
通过 `body_surface_samples` 传入同样的数据；位置点输入不会伪造皮肤。

最终 diagnostics 的 `self_contact` 保存对应关系、候选区间及接触向量
误差。`self_collision` 仍独立报告几何自穿透。末端世界误差、场景接触
残差、时间抖动和场景穿透也继续独立报告。接触向量误差不能当作穿透
深度或最短表面间隙。

核心文件：`data_sources/smplx_surface.py`（源采样）、
`surface_correspondence.py`（机器人表面绑定）、`self_contact.py`
（时序、相对目标和 Jacobian）。依赖均已在项目中：trimesh、SciPy、
libigl、MuJoCo；不再新增一套手写采样或最近三角形算法。

回归包括移动大腿的有限差分 Jacobian、场景接触优先、离开后释放、
后处理保护、重采样身份，以及同时拉近悬空手与保持几何不穿透。
真实源采样报告写入 `out/self_contact_surface_20260911/`。

完整 1529 A/B 及代价见 `out/self_contact_surface_20260911/c167_1529_ab/RESULTS.md`。
