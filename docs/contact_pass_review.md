# 接近表面但交互未确认：保守试验

`contact_pass.review_contact_passes` 是显式调用的源侧试验模块，尚未作为默认
接触识别策略启用。它不推断人的意图，也不把“力学上可选”解释为误碰。
目前只处理比真实擦碰更窄的情形：原始皮肤仍有可解释为真实空隙的间隔，
运动又可以用连续掠过解释。确实触到、可能存在重建错位、运动转向或停留
的候选继续保留。主动轻触和无意擦碰有时仅凭运动无法区分。

## 输入与判据

- 固定源材料点或语义中心的位置，使用原始物体坐标系，消去已知物体运动。
- 整个皮肤采样区域到场景的最小有符号净空；未知内外侧用 NaN，不当作自由空间。
- 原始候选时序、时间戳、环境标识及明确接触/支撑保护时序。
- 调用者明确给出重建和场景配准的综合位置误差预算，单位米。
  数值 SMPL-X 重建残差、接触距离阈值、机器人可达距离均不能代替这个预算。

一个完整候选事件只有同时满足以下条件，才得到 `unconfirmed_pass`：

1. 不含受保护帧，事件前后观测齐全，处于同一物体坐标系。
2. 所有候选帧的最小皮肤净空都大于位置误差预算。
3. 事件及紧邻前后观测的仿射运动拟合最大误差不超过同一预算。
4. 拟合位移超过两个端点的合计位置误差，避免把静止误判为掠过。

没有按秒数/帧数截断接触，没有部位名单，也不使用机器人求解结果分类源人体。
这是一种保守、可解释的几何模型检查，不是已经验证的意图分类器。曲线掠过
可能保留；短触碰若在观测误差内也保留。真实但整体偏移的接触需要额外证据。
若有源整体动力学解释，调用者必须保护全部仍合理的支撑组合，不能只保护
“逐个移除后不可行”的接触。明确源接触标注同样优先。

## 求解衔接

`without_pass_attraction` 返回独立试验任务，原始观测、掩码、世界锚点保持不变，
与审查结果一起存档。候选降级为自由跟随，取消其吸附及接近目标；保留邻近
确认接触的原接近参考，避免删除一个接触后另一个接触的吸附区间被拉长。
必须在完整时序上审查，然后分窗口；已有裁剪/外部接近计划需先回到完整源计划。

区域级表面任务也不能再次把同一未确认候选拉回表面。试验适配器仅关闭该事件
同一刚体区域的吸附目标，真实场景碰撞查询继续保留。防穿透采用原有单侧
碰撞任务；它不会因为机器人在物体外侧就主动拉近。自由手沿用形态适配后的
相对身体目标，世界跟随末端的既有约定保持。

试验调整接受原有累计姿态、根部位移、时间连续性和保留接触误差预算的检查。
仅靠目标误差下降不得接受增加抖动或扭曲的解。

关节连续性按每个关节、每个时刻的一阶、二阶和三阶差分分别约束；预算来自
固定修改前轨迹。总向量范数下降不能抵消某一个关节的尖峰增加。根部平移和
朝向继续保留原有连续性保护。这避免“手臂顺了、脚踝反而抖了”的补偿。

## 可复现试验

`scripts/review_contact_passes.py` 对完整 TRUMANS 源皮肤及原始场景重新查询，
对不同误差假设记录全部事件和保留原因，生成独立 prepared 文件。输入摘要
防止复用不同录制的几何缓存。没有惯性/摩擦输入时明确记录力学未验证。

`scripts/review_pass_trial.py` 从已有轨迹做有界调整：保留接触沿用原采样点，
使用既有几何修正配置，并独立核对所有非线性预算。与之对应，
`scripts/trumans_crossclip_review.py` 可以用相同初始化和配置重新求解整段，
用于观察仅改变候选计划的影响。两者不得混报。

指标应分别报告：保留接触残差、被取消吸附的原候选残差、自由端点世界误差、
根部/关节/朝向抖动、对源及修改前轨迹的姿态误差、真实网格穿透。取消目标
后对应残差增大是允许的，不能通过不再统计它来宣称整体接触精度提高。
