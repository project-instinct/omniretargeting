2026-09-11 碰撞体自碰撞处理

默认启用机器人自碰撞处理，独立于场景的 `penetration_resolver`。检查模型实际碰撞体，
不将可视几何作为额外碰撞体：`contype=0` 且 `conaffinity=0` 的 geom 始终排除，
即使它被显式 pair 引用也不参与此检查。碰撞体可以是 primitive 或 MuJoCo 编译后的
collision mesh；不加载另一套可视网格来做自碰撞。

保留模型的同一焊接体、父子过滤、碰撞位掩码、XML excludes 及有效显式 pair 规则。
碰撞体筛选不依赖名称中是否含有 visual/collision，也不把 geom group 当成统一语义。
没有改变原机器人、场景尺寸或 SMPL-X 数据。

**求解与检查**

- `self_collision.py` 共用碰撞对缓存、包围体筛选、`mj_geomDistance` 和两个 witness
  的相对 Jacobian。距离为正表示间隙，为负表示穿透。零距离缺少接触法向时，使用
  隔离模型的正 margin 查询获得碰撞引擎法向；原模型参数保持不变。无法可靠查询时抛错，
  不将未知距离默认为零。
- 逐帧 QP 使用 `d + J Δq >= minimum_distance - slack`。slack 非负，上限为该姿态
  已有的间距缺口；深穿透可在有限信赖域内分步减小，不能借 slack 任意加深碰撞。
  接触任务仍在原有优先级体系中处理。几何约束不依赖是否开启场景硬约束。
- 单独检查两个端点不够。逐帧求解还对上一保存帧到当前姿态的插值路径生成约束，
  每个碰撞对使用所采样路径上最差 witness 线性化；更新后重新检查完整采样路径，
  必要时缩短本次关节优化步。没有重新引入固定的帧间关节速度/加速度上限。
- 独立逐帧求解器从实际上一输出帧检查初始化路径，不能用独立 baseline 的穿透路径
  定义新的容许上限。无效初始化只缩短内部关节的初始位移，之后仍求解当前帧的源任务。
- 完整流水线保留 baseline 和接触过渡关节混合作为候选，以维持原动作的连续性。
  每次逐帧求解结束后，由 `self_collision_projection.py` 对整条候选轨迹检查并联合
  修复保存帧和帧间碰撞，之后才进入后续 refinement。修复固定浮动基座，使用窗口内
  两端姿态的 Jacobian，并约束新增关节修正、修正速度/加速度和原手脚任务。
  无碰撞候选原样返回，不进行额外场景查询。候选阶段允许的碰撞不构成最终验收豁免。
- `collision_motion.py` 根据几何尺寸和祖先关节估计运动距离。自碰撞使用两个碰撞体
  的相对运动范围，公共浮动基座的刚体平移/转动不触发无意义的自碰撞细分。
- 整段 refinement 加入自碰撞单边距离残差，并对更新后的保存姿态及帧间路径进行
  非线性检查。帧间残差同时使用两个端点的关节 Jacobian，可以主动修复仅在插值中
  发生的穿透。浮动基座保持该阶段输入值，整条轨迹的关节更新一起回溯。
- local repair、双向候选和 DP 验收使用同一碰撞体查询。两体碰撞事件选择能改变其
  相对位置的局部关节链；自碰撞记录不被当成场景障碍构造同侧平面。
- 自碰撞修复窗口独立于场景事件，允许跨接触状态切换，逐帧保留真实接触约束。
  在接触与有界修正约束下，先最小化自碰撞 slack，再优化姿态和时序代价。
  原有场景未知侧仍单独报告，但不再自动阻止已知自碰撞的修复；新增未知 geom/区间、
  可靠场景穿透加深、手脚约束违反及采样预算不足仍会拒绝候选。
  场景 slack 上限仅包含原来超过穿透容差的缺口，不能把整个已有深度变成可新增的
  穿透额度。接近碰撞的帧间 pair 也主动进入 QP，避免只修当前最坏 pair 而撞到邻近部位。
- 最终诊断单列 `self_collision`，包含碰撞体列表、碰撞对数、保存帧最大深度、受影响帧、
  碰撞对及帧间最大深度。关闭时为 `status=disabled`、`max_depth=null`，不会显示成
  已检测且无碰撞。保存帧和帧间复测均独立于局部修复是否启用；`acceptance_status`
  区分 `passed`、`residual` 与 `incomplete`，后两者不能当作通过。

配置示例（可省略，使用默认值）：

```json
{
  "retargeting": {
    "self_collision_enabled": true,
    "self_collision": {
      "detection_distance": 0.03,
      "minimum_distance": 0.002,
      "penetration_tolerance": 0.001,
      "slack_sigma": 0.002,
      "regression_tolerance": 0.000001,
      "motion_spacing": 0.005,
      "max_substeps": 256
    }
  }
}
```

距离单位为米。检测范围、安全间隙、最终穿透容差各有不同作用；检测 3 cm 不表示
要求人体各部位分开 3 cm。旧 profile 显式写了 `self_collision_enabled=false` 的，
会保留关闭选择，需要删去该字段或改为 true。算法仍是有界局部优化和自适应离散路径
检查，不能保证任意初态、不可达接触或超过细分预算的运动连续无碰撞；残余深度和
未完成的检查应查看诊断。
