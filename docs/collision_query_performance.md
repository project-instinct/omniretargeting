# 扫描场景查询效率改进（2026-09-08）

本次只改变 `SceneQuery` 的查询工作量，不改变碰撞几何、容差、表面采样、帧间
插值、接触任务或求解器。当前分支为 `main@e25e4c08`，在原有 dirty worktree
上局部修改；没有切分支、reset、复制官方资产或 push。

## 查询方法

UMR 的候选碰撞对及几何缓存启发了“先排除不能影响结果的查询”的实现方向。
本项目开放扫描面不能按整个场景凸包处理，因此保留 libigl 三角形 AABB 后端，
独立实现以下筛选；没有搬入 UMR 源码。官方版本、许可审阅和函数映射见
[UMR 审阅记录](umr_scene_interaction.md)。

1. `SceneQuery.__init__` 为每个连通块缓存顶点、三角形及包围盒；用固定接触证据到
   实际三角形的最短距离，预先判断证据半径内是否可能存在该块上的点。查询异常时
   保守保留原查询路径。
2. 无证据的开放块始终保留 `uncertain=True`，仍参与最近无符号距离及表面见证点
   的计算。如果其包围盒距离下界已大于当前最近距离，省去不能改变结果的三角查询。
   未删面、未闭合扫描、未改法向，也没有把未知空间标成自由空间。
3. 闭合实体及可能受证据支持的开放块继续完整查询所有点。不能用上述距离下界
   剔除它们，因为较远的表面仍可能代表更深的有符号穿透。
4. 维持原连通块遍历顺序和严格小于比较，最近点并列时的 body/face 对应不变。
   原来的逻辑查询点预算不变；新增 `component_query_points/calls` 只记录实际
   三角查询工作量，不改变预算含义。

## 同一 test data 的实测

输入是 `test_data/c167_1530_final_v3`，使用此前真实 CLI 生成的 144 帧 G1 轨迹、
固定接触任务、原场景及机器人配置。没有重新运行人体模型推理和原始逐帧重定向；
下表测量的是其后的验收阶段，不能当作整条 SMPL-X 流水线的总耗时。

| 检查 | 优化前 | 优化后 |
|---|---:|---:|
| 同一 22 帧、121,682 点查询 | 3.168 s | 0.262 s |
| 完整后处理验收 | 608.795 s | 46.157 s |
| 其中本轮从空缓存执行的几何检查 | — | 45.912 s |
| 本轮验收及局部修复合计（含加载） | — | 47.005 s |

完整验收约快 **13.2 倍**。608.795 s 是此前保存的完整实测；抽样则在本轮编辑前
冻结当前实现，直接与编辑后逐项比较。两项基准均无降低精度：

- 全部 144 个保存帧、3,912 个帧间姿态，共 4,056 姿态、22,433,736 个点重新查询；
  初始缓存为空，没有加载过去已完成的几何结果来冒充加速。
- 保持表面采样间距 2 cm、帧间运动上界间距 1 cm、最多 128 细分；没有区间触顶。
- 抽样输出的距离、方向、最近点、face/component 编号、置信度及不确定标记逐元素
  完全相同。完整验收报告（包括全部穿透记录及接触检查）与之前结果也完全相同。
- 该场景 67 块中，66 块没有任何证据球与其相交。整个运行的实际组件点查询约
  5,081 万次；原来相同逻辑点数逐块查询约需 15.03 亿次。所有块仍保留。

本轮是效率改善，未声称动作质量改善：保存帧最深局部有符号残差仍为 112.821 mm，
31 帧，最差 `left_wrist_yaw_link@77`；帧间为 114.856 mm。开放扫描仍有 144 帧、
143 个区间几何侧不确定，这些数值不是闭合实体穿透真值。四个窗口均因
`uncertain_fixed_boundary` 回退，状态保留 unresolved。

最终 qpos 与原轨迹逐元素完全相同，故根轨迹、窗口外/无关关节、接触位置与模式、
摆动偏离、速度/加速度和水平/垂直修正均未改变；新增关节修正及 slack 均为零。
固定 marker 的各末端接触/摆动残差和局部事件见下面的报告，不以总 loss 代替。
