# 姿态相似度：归一化关系

实现：[`omniretargeting/pose_relations.py`](../omniretargeting/pose_relations.py)。
fast 后端（`--solver fast`）用它度量相对固定参考和原始动作的姿态变化：姿态是软目标，
没有角度上限；唯一的硬规则是布局不翻转。`--solver sequence` 同样不设角度上限。

## 定义

取所有映射关节点，再给每个末端（手、脚、头）加一个末端点。任意两点 i、j 之间：

```
E_ij = (p_j - p_i) / l_ij
```

`l_ij` 是这两点沿本机器人骨架树的路径长度。于是：

- 相邻两点（一根骨头）的 `E_ij` 就是骨头的单位方向，`|ΔE_ij| = 2 sin(Δθ/2)`；
- 不相邻两点的 `ΔE_ij` 是相对位移占这段骨架长度的比例。

方向和位置因此用同一个无量纲量度量，不需要“方向用角度、位置用百分比”两套规则。
整体刚性转动 θ（随机轴）平均使每条关系变化 `2 sin(θ/2)·(π/4)·|E_ij|`；
据此把变化量反算成“等效转角”：

- 整体角：所有点对变化的平均，等效于整个身体转了多少；
- 部位角：某个点所有点对变化的平均，等效于这个部位相对其他部位转了多少。

躯干、髋、肩的改动会牵动几乎所有点对，整体角变化大；前臂、手的改动只牵动
自己的点对，主要体现在部位角。层级由关系图自然产生，不需要手工给各部位分档。

## 软目标与唯一硬规则（2026-09-30）

姿态是最低优先级任务：先保证不穿模和有证据的接触，再用软正则让关系变化相对接触获取前
冻结的参考最小。参考从不改成最新候选，多轮优化不会逐步把机器人拧歪。整体角、部位角、
单关节累计改变、根部朝向、逐骨方向都**没有角度上限**，只报告，最终对照原始动作（肉眼）
判断。原先的 0.2 rad 整体角、0.6 rad 部位角/单关节、0.2 rad 根部朝向上限已删除：
335 份 fast 报告中单关节 0.6 上限在 329 份里被用满，部位角 0.6 上限在 130 份里被用满
（全部是手部末端，截住了手去够接触点）。

| 量 | 处理 |
|---|---|
| 整体角、部位角 | 软正则，报告最大值、帧和部位（`relation_envelope`） |
| 标量关节、根部朝向、逐刚体转动 | 只报告 |
| 与原始动作的关系角、种子逐骨方向 | 只报告（`source_relation_angle_*`、`seed_source_bone_angle_*`） |
| 布局 | 不同肢体之间、肢体与躯干之间，参考姿态朝向坐标系中明确的前后、左右、上下关系（分量不小于 `LAYOUT_MARGIN`，约 0.2 的弦长，只用来判定“明确”）不许翻转；肢体按关键点树自动划分，同一肢体内的弯曲不算布局 |

软正则的单位取机器人与人的形态差（参考姿态到源动作的关系距离，片段中位数），不小于
`POSTURE_SCALE_RAD`（0.2）；它只决定姿态相对其他任务的权重，不是上限。形态差实测（中位数）：
G1 0.33–0.35，T1 0.33–0.39，H1-2 0.34，K1 0.46，PM01 0.49，mini_pi 0.55。

每个候选步都做布局的非线性检查，翻转则回退；备用锥规划步和网格修复使用布局分量的
切平面线性化。报告字段：`layout_flip_frames`、`layout_flip_max`、`layout_preserved`、
`layout_continuity_accepted`。

关节点关系看不见末端肢段绕自身轴的扭转：手腕之后没有别的关节点，拧手不改变任何关系。
这种末端的朝向只由 `_core/orientation_targets.py` 的朝向目标约束，因此没有其他任务看管的
末端（手，有映射时还有头）用更紧的权重跟随标定后的原动作朝向
（`UNOBSERVED_LEAF_SIGMA_SCALE`）；末端链上有脚底朝向跟踪（`track_orientation`）的脚保持
默认权重。只读运动学树和已解析的效应器，不用部位名字，也不需要 profile 配置。

二次修正（网格修复、全身修正、细化）相对它们收到的轨迹保持局部
（`_fast/repair_limits.LOCAL_ANGLE`、`max_joint_correction`），这是修正的局部性，
不是相对原始动作的姿态上限。

## 标定（2026-09-27）

脚本与结果：`out/relation_calibration_20260927/calibrate.py`、`calibration_angles.json`。
在 G1、T1、K1、H1-2、mini_pi、PM01（OMOMO 78/318、AMASS、TRUMANS）上，
单关节转 θ 时整体角约为：根部 1.1θ、腰 0.5–0.7θ、髋 0.3θ、肩 0.15θ、膝 0.14θ、
肘 0.1θ、腕 0.02θ；部位角对肢体关节约为 0.7–1.0θ。不同机器人之间差别很小。

omomo_78 G1 搬箱子：只动手臂把手放回人的接触点（误差约 3 cm）需要整体角约
0.19 rad、部位角约 0.5 rad；旧的逐刚体 0.2 rad 上限下手部残差约 11 cm。这些数值
是删除角度上限之前的历史记录。

## 依据

- Fu 等，Morphology-agnostic humanoid retargeting via perception-motivated graph
  similarity，Frontiers in Neurorobotics 2026：全点对边向量按各自身体的静止长度归一化。
- Bernardin 等，Normalized Euclidean distance matrices for human motion retargeting，
  MIG 2017：归一化距离矩阵表示与体型无关的姿态。
- Molla 等，Egocentric Mapping of Body Surface Constraints，IEEE TVCG 2018：以身体为
  参照的归一化，保持肢体空间次序。

本项目改用骨架路径长度归一化，并把变化量换算成等效转角来报告；这两点是本项目的
做法，不是上述论文的原方法。
