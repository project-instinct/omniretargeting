# 保持原始姿态的碰撞修正调研

调研日期：2026-09-26。范围：游戏角色动画、接触保持 IK，以及本项目 fast 后处理。
本文区分一手资料与代码中可确认的事实、由此提出的推断，以及尚待实验验证的建议。
它不是碰撞修复实验报告，也不承诺零穿透。

## 不可改变的前提

- 源人体动作、场景注册、真实尺度、根路径、时间和运动方向保持不变。
- 原始动作的可辨识姿态与固定的 pre-acquisition 机器人参考包络优先于清除穿透。
  不移动参考，不扩大预算，不把已经变形的入口当作合格参考。
- 接触按源动力学和交互证据保护；未知 hold 继续保护，不能用手脚名称替代证据。
  接触使用原世界目标；自由手保留身体相对、形态缩放语义，脚保留世界目标。
- 每个候选都须保持逐关节、逐时间步的连续性预算、接触精度和姿态边界。
  越界候选应回溯或拒绝，然后继续在原包络内尝试；确实冲突时保留并报告残差。

## 一手资料支持的做法

| 来源 | 已确认的做法 | 本项目可借鉴之处与边界 |
|---|---|---|
| [Epic Full-Body IK 官方文档](https://dev.epicgames.com/documentation/unreal-engine/control-rig-full-body-ik-in-unreal-engine) | Position Based IK；逐骨骼刚度、preferred angles、关节限制；`Pin to Input` 锁根 | 以输入姿态组织局部自由度和关节偏好。官方功能说明不等于源姿态、接触与 jerk 的硬保证 |
| [Müller 等，Position Based Dynamics](https://matthias-research.github.io/pages/publications/posBasedDyn.pdf) | 用约束梯度投影位置；静态穿透采用最近表面点及法线；反复处理约束 | 借鉴局部退出方向和迭代投影。原论文主要展示布料，过约束可能振荡，不能直接将粒子推出结果用作机器人轨迹 |
| [Le Callennec 与 Boulic，Interactive Motion Deformation with Prioritized Constraints](https://www.lecallennec.com/pages/publications/2004_sca/) | 动画编辑先满足高优先级约束，再处理较低优先级约束 | 接触和动作语义应有明确优先级，不能只靠不断调权重保持 |
| [Escande 等，Hierarchical Quadratic Programming](https://gepettoweb.laas.fr/uploads/Publications/2014_escande_ijrr.pdf) | 对等式和不等式建立严格层次，后层保留前层已达最优结果 | 可在已有 SOCP 硬预算之上分层优化；没有必要改成只支持等式的简单伪逆 |
| [Gleicher，Retargeting Motion to New Characters](https://graphics.cs.wisc.edu/Papers/1998/Gle98/retarget-preprint.pdf) | 逐帧 IK 可能在接触切换处跳变；事后低通可能破坏接触；联合优化时间上的修正位移 | 在时间窗口或整段上优化修正信号。论文允许缩放轨迹、移动落脚点的部分不适用于本项目 |
| [Villegas 等，Contact-Aware Retargeting of Skinned Motion](https://arxiv.org/abs/2109.07431) | 同时保留有意义的自接触、地面接触并减少穿透 | 必须区分应保持的交互与不应存在的交叠。论文的手部重点不能成为本项目的接触部位白名单 |
| [Ho 等，Spatial Relationship Preserving Character Motion Adaptation](https://eprints.gla.ac.uk/276398/) | 以 interaction mesh 的局部形变保持身体与环境的空间关系，减少不当穿插 | “动作整体样子”也包含肢体之间的空间关系；这种软形状目标不能代替固定源姿态和接触硬约束 |

共同启示是：从原动作出发，在保持交互的自由度内做小修正，并处理修正的时间连续性。
FBIK、PBD 或其他算法名称本身不能保证原姿态保持，也不能让不相容的硬约束变得可行。

## 最短退出向量的含义

[convex_mesh_distance.py](../omniretargeting/convex_mesh_distance.py) 对编译后的凸碰撞 mesh
使用 Minkowski 支持查询，为重叠求取最小平移退出量的上下界及 witness。
这里的 minimum translation distance（MTD）描述几何体相对平移的退出距离和方向。
**MTD 不是碰撞力，不是冲量，也不是最小关节位移。**

对自碰撞，应使用双方 witness 的相对 Jacobian：`nᵀ(J_a - J_b) Δq`。
接触、关节限位与固定根可能使精确沿 MTD 方向移动不可达；应求原可行域内最接近的改善。
当前法向距离行只约束/优化法向进展，并不强制 witness 的完整位移严格平行于法线。
必要时可在较低层惩罚多余切向位移，但不能因此牺牲已达接触或姿态精度。

## 调研时实现的已确认事实

实现入口：[mesh_repair.py](../omniretargeting/_fast/mesh_repair.py)、
[repair_limits.py](../omniretargeting/_fast/repair_limits.py)、
[self_collision.py](../omniretargeting/self_collision.py)。以下描述本轮对照实验前的实现。

- 根固定，只修改标量关节；局部关节/身体旋转预算为 0.05 rad，并检查固定参考和源骨方向。
- 对每个关节、每个时间步，冻结入口 `|Dq|`、`|D²q|`、`|D³q|`，只允许数值误差。
  自由端到原目标的误差不得增加；其他受保护接触具有毫米级位移边界。
- 目标是碰撞残差平方与整段累计关节位移平方的加权和，归一化尺度分别为 0.01 m 和 0.05 rad。
- 单 body 投影开放其祖先与自身后代，没有自动构造碰撞双方和接触补偿支链的联合变量块。
- 调度最多六组、总计十二次尝试；失败组不重访。每个碰撞 key 的已达深度逐步取最小值保护。
- 分支回溯后还有整体非线性检查与原几何复测；保存帧查询不构成连续无碰撞证明。

另有入口认证问题：`fixed_angles = max(entry_error, default_budget)` 和
`source_bounds = fmax(source_budget, entry_source_error)` 会将已越界的入口误差纳入允许值。
虽然 reference 数组没有移动，这仍不能认证为通过了原固定包络。
现有 fast 入口已经越界的帧必须单独报告；“后处理未进一步恶化”与“满足原预算”是不同结论。
后续实验必须保留原参考和原预算，不能借这类入口容纳逻辑宣布源姿态验收通过。

## 为什么修正可能很小：推断，尚非本数据的因果结论

1. **逐点差分限制可能使可行域很窄。** 对一行 `|a + Dδ| ≤ |a|`，修正差分必须抵消而不能
   增强原差分；`a = 0` 时修正差分也须近乎为零。这比通常动画“禁止新增高频”更严格。
   本项目既已要求这些硬预算，应诊断剩余可行空间，不能悄悄替换成软平滑项。
2. **软姿态正则可能压制可行改善。** 若时序约束迫使单帧碰撞通过整段共同偏移解决，所有帧
   都支付姿态代价。解析示例：168 帧、一个恒定关节偏移、一帧 7 cm 穿透、Jacobian 0.4 m/rad，
   使用上述归一化尺度，未加其他约束的最优偏移仅约 0.233°。这不是实际 G1 测量。
3. **变量选择可能遗漏接触补偿。** 某祖先关节影响其他受保护末端，而它们的补偿关节未开放时，
   该祖先可能实质锁死。自碰撞双方联合调整可能使用单侧无法利用的自由度。
4. **有限调度可能早停。** 六组、每组少量尝试与失败后不重访不能证明达到预算内最优。
   分支回溯只有在约束确实跨组耦合时才可能破坏联合补偿；不能直接认定这是 G1 的瓶颈。

## 建议与最小对照实验

“姿态优先”应通过固定硬包络表达。若先严格最小化姿态改变量，零修正总是最优，后层碰撞无从改善。
建议在完全相同的硬预算内，先求可达的碰撞改善，再在保持该改善的条件下最小化累计改动。
可先最小化最坏穿透，再处理剩余残差，最后优化关节/骨架位移和修正的时间变化。
所有阶段仍由同一份源参考、机器人参考和接触目标约束。

| 对照 | 保持不变 | 唯一变化与问题 |
|---|---|---|
| A：基线诊断 | 原 entry、参考、几何、所有预算 | 记录变量列、活跃预算、回溯原因、预测与真实改善 |
| B：联合投影 | 同一硬预算与目标 | 开放碰撞双方及必要接触补偿支链，先检查整体候选；检验是否遗漏可行自由度 |
| C：分层目标 | 同一变量与硬预算 | 先减少碰撞，再最小改动；检验姿态软正则是否压制可行改善 |
| D：有限重访 | 最佳方案的全部硬约束 | 重访碰撞组直到无改善或显式计算限额；检验调度早停 |

联合变量块可从碰撞双方开始，加入祖先及保持受影响接触所需的补偿支链。
“所有标量关节开放、根固定”可作为诊断上限对照，然后收缩至必要块；开放变量不等于放宽预算。
接触严格等式的零空间可用于诊断或参数化；毫米容差、姿态范数和限位仍应保留为不等式。

对最坏 witness，另求一次“同一线性化和原预算下最大可行退出量”。
若近零，只能说明该局部线性化受阻；若明显非零而实际更新很小，应检查目标、投影和回溯。
此诊断不能证明整个非线性问题全局无解。时间参数化可用于改善条件数，但仍须检查所有帧和窗口边界。

## 验收与结论边界

- 每个候选用原几何重新查询；保留未知几何、失败查询、碰撞 pair 和受影响帧，不伪造清零证书。
- 静态场景、移动物体、自碰撞分别报告前后最大深度、部位、帧及残差分布。
- 报告 witness/末端修正的水平与竖直分量、世界末端误差、接触残差、自由端误差和根严格不变。
- 逐关节、逐时间步检查 v/a/j；分别比较源骨方向、固定机器人参考和累计局部修正。
  源动作本身的快速变化与新增抖动分开计量，不能只看全身平均值。
- 保存帧与帧间轨迹分别检查；有限采样与细分上限须明确，不能推导连续安全性。
- fast 的入口越界、`budgets`、`skipped_tasks` 与后处理改善分别报告。
  本文仅提出可验证方案；任何真实改善数字应进入独立实验记录，并接受原始姿态包络验收。
