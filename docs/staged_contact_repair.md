# 固定其他接触的分阶段穿模修正

严格 `sequence` 后端可显式启用：

```json
{"sequence_solver": {"staged_contact_repair": true}}
```

这个可选阶段在源形参考、全身接触获取和原有整段求解之后执行。`fast` 和
`mink` 不能启用该选项；它依赖每一步都检查的姿态、接触与连续性约束。

`staged_contact_repair.py` 根据原始静态网格采样和运动物体的正向、反向
穿透见证，找出仍穿模的活动接触刚体。按已有的支撑、未解释保持、物体
控制和跟随角色排序，同一焊接刚体的表面点合为一组，不按身体部位名字
硬编码支撑规则，也不把普通接触提升为支撑。

每组先尝试固定浮动根部的关节修正。只有该组的多个退出见证一致向上，
且用户没有锁定高度，才尝试小幅根部升高。此时根部水平位置和朝向仍然
固定，逐帧高度不超过当前穿透深度加原有净空量；固定源形参考的累计
3 cm 平移包络（默认配置）仍然独立生效。非竖直的碰撞继续使用完整退出
方向进行关节修正，不会被强制改成向上退出。

`_sequence/contact_hold.py` 对其他接触增加**相对已达到位置的向量约束**。
仅约束“到目标的距离不增加”会允许接触点沿等误差球面滑动，因此不够。
保持容差至多 0.1 mm；滑动接触保持逐帧已达到的轨迹，不把它冻结成跨帧
不动的点，也不允许另加切向漂移。被调整的
接触仍受原始接触误差预算保护。完成一组后只冻结这一组的新位置，其他
组的保持参考不更新，避免后续阶段累计拖动支撑。

各阶段围绕同一个修正前机器人输入惩罚身体位置位移，并共享同一个
接触获取前的姿态和逐关节速度、加速度、jerk 预算。另加一套固定于修正
开始时的已获取连续性预算，防止修正重新用掉接触获取阶段已经节省的
抖动余量。修正目标只包含净空和最小位移，不重新拟合无关的自由肢体。
最终接触位置和连续性也会保留给下游验收。机器人关节限位、
相对源动作的骨骼方向约束以及全身累计朝向限制均保留。它是有界非线性
局部最小改动求解，不保证全局最短位移；冲突时保留残差，不放宽参考。

接受阶段输出还要求每帧、每个刚体的采样穿透深度不增加，且当前目标组
的穿透总量下降。完整的原始场景、帧间子姿态、自碰撞与最终接触验收仍由
原有主流程负责；采样诊断不是无碰撞证明。各阶段报告包含接受原因、
最深穿透的刚体和帧、退出向量水平/竖直分量、其他接触的位移以及固定
姿态包络检查。

保存结果可通过 `scripts/trumans_review_solve.py --staged-contact-repair`
复核，必须提供 `--contact-reference` 与 `--correction-reference`。
导出的源侧角色会按原时间线恢复；缺少自由空间证据时保守地保留保护。
如果输入已经超出固定参考的姿态或逐关节连续性预算，会输出
`input_exceeds_fixed_budgets` 并保持输入。此时应从原有源形参考重新获取
接触，不能把超预算结果当作新的参考来绕过验收。

针对性测试：

```sh
pytest -q tests/test_staged_contact_repair.py tests/test_contact_priority.py
```

案例覆盖座面接触抬升时两个支撑点保持位置、等误差绕目标运动的拒绝、
任意部位的全身接触、根部锁定和非向上退出、不累计重置其他接触锚点、
源角色导出恢复，以及拒绝用新参考掩盖已有抖动。
