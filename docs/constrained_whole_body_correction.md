# 受约束全身接触与运动物体避碰

实现入口：`omniretargeting.whole_body_correction.correct_whole_body_trajectory`。
CLI 在帧级求解、既有轨迹后处理和局部修复之后调用此阶段。输入为已经有效的机器人
轨迹；输出仍使用原始时间轴、原始人体和物体运动以及真实机器人尺寸。

## 从 UMR 采用的机制

方法审阅固定于 UMR commit
[`e24fc070030dc0bb0b2c024ecb9f795a3995d725`](https://github.com/hanyang9/UMR/tree/e24fc070030dc0bb0b2c024ecb9f795a3995d725)。
具体来源和未采用的默认配置见 commit `b4b0939` 中的 `docs/umr_constrained_whole_body_plan.md`。

- 复用学习得到的固定人体三角形/重心坐标与机器人局部表面点对应；接触向量保持同一个
  源侧环境点分配。求解和验收不重新选择更有利的表面点。
- 接触位置、表面姿态和碰撞在同一阻尼关节修正问题中共同起作用。活动手接触不再把
  新阶段限制在手臂；骨盆/腰腿所需祖先关节与手脚补偿链一起参加。
- 机器人参考法向按源表面的参考姿态变化运输：
  `n_target(t) = R_source_face(t) R_source_face(rest)^T n_robot(rest)`。
  新的 `pose_normal_targets` 与环境接触 `normals` 分开，避免要求不同形态的皮肤法向
  直接相同。无效源三角形仅禁用对应的法向项。
- 几何间隙通过机器人碰撞点的 Jacobian 产生关节修正方向。物体位置、旋转和尺度是
  给定的源信号，不进入优化变量；不统一向上推、不改变场景。
- 碰撞使用非负松弛。按物体、碰撞体、帧/帧间区间的最差深度计费，采样数量和网格
  三角剖分不能任意放大其优先级。报告保留线性化松弛和实际非线性几何结果。

## 本项目保留的约束

整个阶段使用同一份机器人基准，不能每迭代一次就重置误差预算。

| 项目 | 默认预算/处理 |
| --- | --- |
| 浮动根 | qpos 逐位固定；球关节也不属于当前标量关节求解变量 |
| 抓握 | 固定机器人材料标记；逐帧接触误差最多比基准增加 1 mm |
| 滑动 | 分别保护法向误差与切向跟随误差，最多各增加 1 mm |
| 脚部 | 相对基准世界位置最多移动 2 mm；原始世界目标不变 |
| 自由手 | 不新增人体手的绝对世界位置目标；保护既有机器人姿态和小幅偏移预算 |
| 标量关节 | 总改变量最多 0.2 rad（滑动关节为 m），每步信赖域 0.06 |
| 修正速度/加速度/jerk | 1、12、240，分别为 rad/s、rad/s²、rad/s³；滑动关节使用 m |
| 时间正则 | 惩罚新增修正的差分，不低通原始动作，不削弱刻意的快速运动 |
| 场景和自碰撞 | QP 内线性保护；接受前重新做实际 FK、几何与帧间检查 |

存在较大基准接触误差时，可以向原始目标改善；这些预算不是要求机器人达到源动作中
不可达的位置。关节限位和固定根造成的不可动目标会记录在 `surface_scope` 和
`moving_collision.immovable_witnesses` 中。

## 运动物体几何

`MovingSceneQuery` 固定原始物体局部网格及其材料采样，逐帧更新原始 `R,t,s`。

1. 对可靠闭合组件，在固定机器人碰撞表面采样上查询原始三角形有符号距离；组件分开
   验收，不能用一个组件的改善掩盖另一个组件的退化。
2. 对物体所有原始顶点和所有三角形重心，补充“物体表面进入机器人碰撞体”的反向
   查询。机器人 mesh 使用 MuJoCo 编译后的凸碰撞表示；曲面 primitive 使用内接
   采样凸壳。因此该结果是采样交叉证据及深度下界，不是物体实体的内外判定。
3. 开放组件继续记为未知。当前实现没有把整把椅子凸化，也没有自动制造未经验证的
   CoACD 代理；原始椅背/椅腿之间的空隙保留。
4. 为控制子问题规模，反向线性化保留每个退出平面的最深材料点，并显式记录候选/
   选中行数。接受检查仍覆盖全部原始材料采样，不用线性化行的数量声称几何覆盖。

帧间细分的位移上界包含机器人关节运动以及物体的平移、旋转和尺度变化。因此静止
机器人也会检查运动物体从中间穿过的情况。碰撞行同时作用于相邻两帧的关节变量；
达到细分上限会报告预算不足，不能当作没有碰撞。

主要手部目标在帧间按物体材料坐标运输，保持原来的世界接触间隙。关闭物体避碰做
对照时仍应传入原始 `scene_objects`，仅切换 `moving_collision_enabled`，否则手部
帧间目标的插值也会改变，不能算同条件对照。

## 接受与回退

每一步先求解稀疏轨迹子问题，再做回溯。候选必须降低实际非线性目标，并通过固定
标记的手脚误差、修正幅度/时间差分、静态场景、自碰撞、运动物体及帧间验收。
已有未知场景不能隐藏已知样本退化。未通过的候选不进入输出；`no_feasible_update`
与零次接受不会被标为修复成功。

这些检查是有明确采样间隔的离散检查，不是连续无碰撞证明。若最深交叉位于携带
浮动根的躯干刚体，其对全部标量关节的 Jacobian 为零，此阶段不会为了消掉该深度
移动人体或漂移机器人根路径。其他关节能够改善的接触/交叉仍可独立修正并报告。

## 配置与复现实验

默认开启；可以在 robot profile 中覆盖：

```json
{
  "retargeting": {
    "whole_body_correction": {
      "enabled": true,
      "moving_collision_enabled": true,
      "iterations": 3,
      "max_joint_correction": 0.2,
      "contact_regression": 0.001,
      "foot_position_budget": 0.002
    }
  }
}
```

也可以直接加载已有 qpos 调用入口，避免重跑帧级脚部基准。任务、场景、机器人模型
必须一致；`contact_offset_choice` 可显式传入原始固定标记索引。切窗口时同时切分
物体姿态及所有任务数组，并保留全片段的表面权重归一化。

OMOMO 三组验证产物位于 `out/umr_whole_body_20260914/`：当前有效 ON 轨迹、全身
修正、全身修正加运动物体避碰。源片段为 `sub13_whitechair_000`，115 帧、30 Hz。
接触、脚部误差、时间抖动、可靠穿透、反向交叉与未知几何分别报告。

完整对照与 486 项通过的回归结果见 [实测报告](../out/umr_whole_body_20260914/RESULTS.md)。
在该片段上，全身参与解决了骨盆运动链被冻结的问题；受固定根和手脚预算限制，
骨盆误差仍约 25 cm。开启物体避碰后仅接受一次小幅更新，不能将功能接入视为
这段动作已经获得显著接触改善或无交叉结果。
