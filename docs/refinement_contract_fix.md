# Refinement 与最终验收的契约修复

本轮针对 2026-09-11 诊断发现的实际冲突，保留现有接触、穿透和保真预算。
没有修改源 SMPL-X、场景、机器人尺度或逐帧目标优先级。

## 实现

- `_refinement/effectors.py` 传递 `track_swing`，`tasks.py` 只在接触或
  开启自由位置追踪时添加位置残差。关闭自由手位置追踪仍保留接触、
  arm posture 和朝向任务。
- `core.py` 在 refinement 前完成基线关节限位和机器人足端保护参考，
  refinement 与最终验收使用同一个基线。主流程跳过会移动根的旧
  foot stabilization／ground lock／XYZ nudge，运行诊断同步标为未启用。
- 新增 `_refinement/guard.py`，复用 `TrajectoryValidator` 的任务、
  接触 marker、预算和几何检查，使用现有 CVXPY/CLARABEL 求解稀疏
  最小二乘目标。约束包括相对原基线的累计关节修正、修正的一二阶差分、
  自由末端位移、接触残差与漂移、支撑滑移、接触朝向和可信场景深度。
  差分约束限制新增修正，不限制源动作本身的速度。
- 线性约束之后仍用真实 FK 和原有密集／自适应帧间几何检查验证候选，
  必要时缩短本次关节步长。求解失败、预算耗尽或找不到可行步长时，
  保留最近通过检查的轨迹。几何不确定性不算安全或穿透改善证据。
- 开启可选平滑时，如果平滑结果超预算，保留已验证的 refinement，
  避免最后把这部分有效工作一起回退到 framewise baseline。
- 直接调用 `refine_joint_trajectory` 而不提供 guard 时，仍保留原有
  box-bound `lsq_linear` API；其穿透项是软惩罚，不能替代最终验收。

主流程诊断增加 `trajectory_refinement`，记录终止状态、各轮实际步长、
拒绝原因、末端保真、可信深度和未解决的不确定几何。采纳次数与改变帧数
独立记录；采纳率高不能用来证明动作更准或场景无穿透。

## 验证范围

行为回归包含：关闭自由位置后接触／朝向／手臂形状仍生效、固定根、
多轮累计预算、1 mm 世界足端预算、场景约束方向、错误基线拒绝及
坏平滑保留正确 refinement。另用 free + hinge + ball + slide 模型
验证不连续 qpos/dof 索引，free/ball 坐标不变。

本轮真实实验复用 `out/her_c167_1530_balanced_registered` 的 143 帧
逐帧输出、原始场景和已保存接触证据，只重跑 refinement 和生产
`select_safe_postprocessing`。未重跑逐帧求解或最后局部碰撞修复，
因此不冒充完整新 CLI 运行，也不是和上游的头对头实验。

可复现入口：`.venv/bin/python /tmp/run_refinement_contract_fix.py`。
数据产物放在 `out/refinement_contract_fix_20260911/c167_1530_two_iterations/`。

短窗口耗时采样使用原序列 68–75 帧，1 次迭代，19.957 s 中密集几何
检查占 19.499 s，CVXPY solve 仅 0.230 s。此处只诊断瓶颈，不能外推
为全序列性能或全身动作精度结论。原始采样日志在
`/tmp/omniretargeting_fix_profile.log`。

## 两轮真实片段结果

本次固定为 **2 轮 refinement**，生产默认仍为 16 轮；采用查询去重后的
代码，未改帧数、fps 或几何分辨率。候选经生产 selector 后采纳率为
**1.0，143/143 帧确实改变**，并非零变化候选得到的虚假进展。
浮动基座完全相同，源人体与场景文件未写回。

| 指标 | 逐帧基线（旧流程实际保留结果） | 本次两轮 refinement 验收结果 |
| --- | ---: | ---: |
| 左脚世界位置误差，均值／最大 mm | 40.801 / 167.073 | 40.759 / 166.977 |
| 右脚世界位置误差，均值／最大 mm | 52.350 / 133.758 | 52.274 / 133.800 |
| 自由左手世界位置误差，均值／最大 mm | 173.057 / 329.351 | 171.140 / 328.528 |
| 自由右手世界位置误差，均值／最大 mm | 227.795 / 451.883 | 226.601 / 449.146 |
| 左手接触法向残差，均值／最大 mm（24 帧） | 56.099 / 164.513 | 54.772 / 164.250 |
| 关节加速度，RMS／最大 rad/s² | 23.351 / 71.856 | 21.159 / 74.102 |
| 关节 jerk，RMS／最大 rad/s³ | 850.328 / 4307.066 | 744.312 / 4321.454 |
| 可信最大场景穿透 mm | 19.797 | 19.413 |

自由手世界位置只作诊断，不是本项目的自由手优化目标。其他末端没有
接触样本，不应把缺失的接触／支撑滑移指标解释成零误差。
jerk RMS 下降约 12.5%，但最大 jerk 略升；这些是时间差分统计，
不能单凭它们证明每一帧都更平滑或全身姿态都更准确。

两次可信最大深度均在第 74 帧（从 0 起）`left_wrist_yaw_link`。
原最深碰撞点的实际关节修正向量为约
`[-0.150, -1.613, +2.022] mm`，水平模长 `1.620 mm`，竖直 `+2.022 mm`。
使用完整退出方向，没有移动根或人为分成“横向/竖向”两类。

左、右脚相对基线的最大 marker 位移分别为 `0.223 / 0.242 mm`，
均在原有 1 mm 预算内。可信帧间最大深度也为 `19.797 → 19.413 mm`。

所有 143 帧／142 个帧间区间仍含至少一个不确定几何样本。
包含这些不确定读数的原始最大深度约为 `688.661 → 688.269 mm`，
原始帧间最大深度约 `887.773 mm` 不变；不能把这些原始读数的微小
变化算作修复收益。验收结论是允许保留相对于基线的非退化候选，
不是场景无碰撞认证。左手接触最大残差仍约 164 mm，需要后续独立处理。

两轮 refinement 加最终 selector 共 **354.6 s（约 5.9 分钟）**。
密集帧间检查仍是主要成本。另一次 16 轮实验在保留 5 次更新后主动
停止以控制本轮验证时长，其日志保留在 `/tmp/omniretargeting_real_fix.log`；
未报告默认 16 轮的最终效果。没有同预算、同机器负载的端到端计时 A/B，
不能据此声称本轮获得某个整体加速倍数。

完整数值与轨迹在
`out/refinement_contract_fix_20260911/c167_1530_two_iterations/report.json`、
`accepted_qpos.npy`。同目录 `reproduce.py` 可重跑两轮实验。
